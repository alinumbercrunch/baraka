# Baraka — prototype

A prototype website for **Baraka (バラカ)** — an online catalogue where interior
designers and small real-estate companies in Shonan / Tokyo / Kanto discover and
buy work by artists who are not yet widely known.

One artist is featured each month. Their work stays for sale afterwards.

## ⚠️ This is a prototype

- Artist names, work titles, prices and biographies are **fictional samples**.
- Artwork images are **public-domain museum works** used as placeholders.
  The dimensions shown are those works' real dimensions.
- The email address and phone number are not real.

## The idea

Every work is shown **uncropped, at its true size relative to every other work**.
One shared millimetres-per-pixel value across the whole site. A 364 mm watercolour
really does appear about a seventh the height of a 2,717 mm canvas.

Enter your wall dimensions and each work tells you whether it fits, and at what
height to hang it.

## Built with

Plain HTML, CSS and vanilla JavaScript. No build step, no framework, no
dependencies. Fonts from Google Fonts. Everything else is in this folder.

## Pages

| File | What it is |

| `artist-*.html` | One page per artist |
| `bk*.html` | One page per artwork |
| `trade.html` | Terms for designers, real-estate firms and artists |
